# AI Power User → AI Builder Roadmap

A friendly, interactive guide for moving from AI beginner to AI-native builder and systems thinker.

## What’s included

- A 12-stage learning path
- 30 curated learning resources with direct links
- A–AH skills map and searchable glossary
- A nine-project hands-on learning ladder
- Search, filters, dark mode, and mobile layout
- Course checkboxes and local progress tracking

## Run it locally

No installation or build step is needed. Open `index.html` in a modern browser.

Progress and appearance preferences are stored only in that browser’s local storage.

## Publish with GitHub Pages

1. Push this repository to GitHub.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select the `main` branch and the `/(root)` folder, then save.

GitHub will provide a public URL after the site deploys.
